# Ilustraciones de grupos musculares

Recursos para las tarjetas principales de la Biblioteca, no iconos de 24 px.
Cada tarjeta muestra una escena real de ejercicio de la biblioteca editorial
validada: misma línea de tinta marfil, fondo grafito y músculos activos en
naranja. Todas se normalizan a un lienzo de `240 × 300 px`.

| Espalda | `espalda-card-v1.webp` |
| Hombros | `hombros-card-v1.webp` |
| Bíceps | `biceps-card-v1.webp` |

| Isquios y glúteos | `isquios-gluteos-card-v1.webp` |
| Gemelos | `gemelos-card-v1.webp` |
| Core | `core-card-v1.webp` |

Las tarjetas usan el nombre como texto principal y la ilustración como refuerzo
visual. Carga diferida, `object-fit: contain` y tamaño visible aproximado de
72–96 px. No usar estas imágenes durante el registro de series.
