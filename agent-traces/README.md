# Trazas de agentes

Cada tarea multiagente produce aquí una traza Markdown basada en `AGENT-TRACE-TEMPLATE.md`.

La traza muestra quién trabajó, con qué modelo y esfuerzo, qué skills utilizó, archivos inspeccionados o modificados, verificaciones, hallazgos y decisiones de Opus. Es un registro de ejecución verificable; no contiene razonamiento interno detallado ni datos sensibles.
